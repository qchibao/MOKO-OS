# MOKO Design System v0.1

## Visual direction
The approved direction is bright, premium and calm: white/ice surfaces, cool blue accents, soft depth, strong black MOKO wordmark and selective colorful app identity.

## Core tokens
- Background light: `#F7FBFF`
- Background blue: `#DCEEFF`
- Text primary: `#101216`
- Text secondary: `#5E6A79`
- Accent: `#3F7CFF`
- Accent light: `#78B8FF`
- Glass fill: white at 60–80% opacity
- Glass stroke: white at 55–85% opacity
- Corner radius: 18–28 px desktop; 20–32 px mobile

These are bootstrap values, not a final brand specification.

## MOKO icon language
Do not copy the Apple Finder face, Safari compass, macOS Photos flower, App Store A, Settings gear or other distinctive platform marks.

MOKO glyphs should be built from a small geometry vocabulary:
- orbital rings;
- stacked planes;
- wave bars;
- split capsules;
- hex/diamond shields;
- faceted prisms;
- rounded nodes.

The initial QML preview draws symbolic glyphs programmatically so the project is not blocked on final SVG exports.

## Layout
Desktop concept:
- 40 px top bar;
- launcher panel left;
- AI panel right;
- centered MOKO identity/quiet desktop space;
- floating bottom dock;
- panels use restrained translucency and border separation.

## Motion
- panel reveal: 180–240 ms;
- dock hover: 120–160 ms;
- modal transition: 220–300 ms;
- avoid constant ambient animation that wastes battery.

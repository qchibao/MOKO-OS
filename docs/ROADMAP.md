# MOKO OS roadmap

## Phase A — Developer Preview
- Bootable Debian-based live image.
- Wayland session.
- MOKO Shell starts automatically.
- Bright MOKO design language.
- No destructive installer.

## Phase B — Real shell
- Desktop-entry application model.
- Launch/close/focus applications.
- Notification plumbing.
- quick settings backed by system services.
- multi-monitor and HiDPI tests.

## Phase C — MOKO Core
- settings service.
- power service.
- network abstraction.
- hardware diagnostics.
- permission/action broker.

## Phase D — MOKO applications
- Files.
- Settings.
- Terminal.
- Store/package frontend.
- Installer.

## Phase E — MOKO AI
- provider-agnostic daemon.
- local/remote model adapters.
- voice input/output.
- permissioned system actions.
- semantic local search/indexing.

## Phase F — Native compositor
- window management.
- workspaces.
- global shortcuts.
- shell/compositor protocol.
- effects and animations.

## Phase G — Hardware certification
- representative Intel PC.
- representative AMD PC.
- Intel Mac non-T2.
- T2 compatibility track.
- NVIDIA track.

## Phase H — Installer/recovery
Only after Live USB reliability is demonstrated.
